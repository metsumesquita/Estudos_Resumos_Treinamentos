1. O que é abt 

No contexto de computação e tecnologia, **ABT** é a sigla para *Analytical Base Table* (ou Tabela Base Analítica). Trata-se de uma tabela de dados estruturada ("plana") em formato de linhas e colunas usada especificamente para treinar algoritmos de Inteligência Artificial e *Machine Learning*

**Como funciona no dia a dia da área de dados**A criação de uma ABT exige a união de várias bases de dados diferentes de um mesmo sistema ou empresa (por exemplo: unir a tabela de cadastros com a tabela de pagamentos e a de interações do usuário). Esse processo — que envolve filtros, agregações e cruzamento de tabelas — costuma ser feito utilizando bancos de dados ou plataformas de integração para garantir que tudo fique pronto para o treinamento de IA

o que é o product owner

**Product Owner (PO)**, ou "Dono do Produto", **é o responsável por maximizar o valor de um produto e o trabalho da equipe de desenvolvimento**. Ele atua como a ponte principal entre os objetivos de negócio da empresa e os desenvolvedores, garantindo que o time construa a coisa certa

#AZURE

O AAS (Azure Analysis Services) e o SSAS (SQL Server Analysis Services) se baseiam na tecnologia de modelagem de dados de BI madura usada por inúmeras empresas. A mesma tecnologia também está no centro dos modelos de dados do Power BI.
